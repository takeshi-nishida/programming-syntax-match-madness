# Reflex
Match Madness Game for Programming Language Syntax.

[Live Demo](https://takeshi-nishida.github.io/programming-syntax-match-madness/)

## How to play

- Match pairs with the same meaning by picking one card from the left and one from the right.
- Clear all pairs to finish the level.

## Install and run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173 and play.
